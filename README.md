README: Лабораторная работа №4
Тема: Базовая безопасность API и авторизация по ролям
Цель работы:
Внедрение механизмов аутентификации и авторизации в сервис управления конференциями с использованием Spring Security и базы данных PostgreSQL.
Реализованный функционал:
Интеграция Spring Security: Приложение защищено с помощью Basic Auth. Доступ к API ограничен для неавторизованных пользователей.
Хранение пользователей в БД: Реализованы сущности User и Role. Данные пользователей (логины и хэшированные пароли) хранятся в PostgreSQL. Связь между пользователями и ролями реализована через таблицу users_roles (Many-to-Many).
Шифрование паролей: Используется алгоритм BCryptPasswordEncoder. Пароли никогда не хранятся в открытом виде.
Разграничение прав (RBAC):
ROLE_ADMIN: Имеет полные права на управление мероприятием (создание, редактирование, удаление событий, сессий и спикеров).
ROLE_USER: Имеет права только на просмотр информации (GET-запросы) и саморегистрацию.
Процедура регистрации:
Реализован эндпоинт POST /api/auth/register.
Валидация: Внедрена проверка сложности пароля (минимум 8 символов + наличие специальных знаков).
Стек технологий:
Spring Boot 3.x, Spring Security 6.
Spring Data JPA, PostgreSQL.
Lombok, BCrypt.

README: Лабораторная работа №4
Conference Management System (Lab 4: Basic Security & RBAC)
📌 Описание проекта
Серверная часть системы управления научными конференциями. Проект реализует полноценный жизненный цикл мероприятия: от создания события и сессий до регистрации участников. На данном этапе в проект внедрена система безопасности на основе ролевой модели доступа (RBAC) и интеграция с базой данных PostgreSQL.
🛠 Технологический стек
Язык: Java 21
Фреймворк: Spring Boot 3.5.9
База данных: PostgreSQL
Безопасность: Spring Security 6 (Basic Auth)
Инструменты: Hibernate, Spring Data JPA, Maven, Lombok
🔐 Архитектура безопасности (Lab 4)
Реализована классическая схема аутентификации и авторизации на стороне сервера.
Аутентификация (Basic Auth): Доступ к защищенным ресурсам требует передачи учетных данных в заголовке запроса.
Ролевая модель (RBAC):
ROLE_ADMIN: Имеет полный доступ к CRUD-операциям (создание мероприятий, удаление сессий, управление спикерами).
ROLE_USER: Имеет право на просмотр данных (GET) и выполнение базовых операций (регистрация).
Безопасность данных:
Пароли хранятся в PostgreSQL в виде хэш-сумм (BCrypt).
Валидация паролей при регистрации: проверка на минимальную длину (8 символов) и обязательное наличие специальных символов (!@#$%^&*).
